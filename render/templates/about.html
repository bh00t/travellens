TravelLens India

A real-time hotel and tourism intelligence platform for the Indian hospitality market. Ask questions in plain English — get charts, insights, and review analysis instantly.

Try the Explorer View Dashboard
Capabilities
What it does

Natural Language Queries

Ask "top 5 cities by revenue" — no SQL required. A local LLM generates and runs the query against Postgres.

Semantic Review Search

Find reviews by meaning, not keywords. "AC not working" surfaces "room too hot" — powered by pgvector embeddings.

Live Streaming Data

Booking events flow through Kafka in real time. Hourly city aggregates keep dashboards showing current data.

Pinnable Dashboard

Pin any result as a widget. Auto-refresh, resize, reorder. Build your own intelligence view — no fixed reports.

Pipeline
How it works
01

You ask

Type a question in plain English in the Explorer.

02

Router classifies

A keyword classifier picks the SQL path or the semantic path.

03

AI fetches

Ollama generates SQL, or pgvector finds the most similar reviews.

04

Widget renders

The result auto-detects its best form — chart, table, or stat card.

Data sources
30K

Hotel Reviews

Real reviews from MakeMyTrip and OYO (Kaggle), embedded into 384-dimensional vectors and indexed with pgvector IVFFlat for cosine similarity search.

1M

Booking Events

Simulated booking records seeded from real Indian hotel IDs. A Kafka producer streams live events with configurable chaos injection for failure testing.
